Every HLD answer follows 7 stepsहर HLD जवाब के 7 steps

  1. Requirements (5 min). What must it do (functional)? How many users, how fast, how reliable (non-functional)?Requirements (5 मिनट)। इसे क्या करना है (functional)? कितने users, कितना तेज़, कितना भरोसेमंद (non-functional)?
  2. Estimation (3 min). Users per day → requests per second → storage.Estimation (3 मिनट)। रोज़ के users → requests per second → storage।
  3. APIs (3 min). The 3–5 main endpoints.APIs (3 मिनट)। 3–5 मुख्य endpoints।
  4. Data model (5 min). Main tables and which database.Data model (5 मिनट)। मुख्य tables और कौन-सा database।
  5. High-level diagram (10 min). Client → load balancer → services → cache, database, queue.High-level diagram (10 मिनट)। Client → load balancer → services → cache, database, queue।
  6. Deep dive (15 min). Go deep into the 1–2 hardest parts.Deep dive (15 मिनट)। 1–2 सबसे मुश्किल हिस्सों में गहराई से जाओ।
  7. Trade-offs (5 min). What breaks at 10x scale? What would you change?Trade-offs (5 मिनट)। 10 गुना scale पर क्या टूटेगा? आप क्या बदलेंगे?
