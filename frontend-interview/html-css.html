CSSCSS

Q1

Explain the CSS box model. What does box-sizing: border-box do?

3–5 yrs🔥 Very common
Show answer

🟢 In simple words: Every element is a box: content inside, then padding, then border, then margin outside.

🖼️ Picture it

Every element is a box with four layers, from inside out: content → padding → border → margin.

By default (content-box), width sets only the content, so padding and border are added on top. With border-box, width includes padding and border, so a 200px box stays 200px. Most projects set * { box-sizing: border-box; } at the start.

💡 Easy example: A gift box: the gift is the content, the bubble wrap is padding, the cardboard is the border, and the space you leave between boxes on the shelf is margin.

🗣️ Say it in one line: Content, padding, border, margin; border-box makes width include padding and border.

Q2

Flexbox vs Grid: when do you use which? How do you center a div?

3–5 yrs🔥 Very common
Show answer

🟢 In simple words: Flexbox lines things up in one row or one column. Grid places things in rows and columns together.

Flexbox is for one direction: a row or a column, like a navbar or a row of buttons. Grid is for two directions: rows and columns together, like a page layout or a card gallery.

Centering is easiest with either one.

/* Flexbox */
.parent { display: flex; justify-content: center; align-items: center; }

/* Grid: shortest */
.parent { display: grid; place-items: center; }

🗣️ Say it in one line: Flex for one direction, grid for two; display: grid; place-items: center centers anything.

Q3

What is CSS specificity?

3–5 yrs
Show answer

🟢 In simple words: When two CSS rules fight, the more specific one wins: inline style beats id, id beats class, class beats tag.

When two rules style the same element, the more specific selector wins. The order from weak to strong:

  • element (p) < class / attribute / pseudo-class (.btn, :hover) < id (#save) < inline style
  • !important beats all of them, which is why it should be rare.

If specificity is equal, the rule written later wins.

🗣️ Say it in one line: Inline beats id, id beats class, class beats element; on a tie the later rule wins.

Q4

Explain position: static, relative, absolute, fixed and sticky.

3–5 yrs
Show answer

🟢 In simple words: Position decides what an element is placed against: its normal spot, its parent, or the screen.

  • static: the default, normal flow.
  • relative: stays in the flow, but you can nudge it. It also becomes the anchor for absolute children.
  • absolute: taken out of the flow, placed relative to the nearest positioned parent.
  • fixed: placed relative to the screen and stays during scroll, like a WhatsApp chat button.
  • sticky: normal until you scroll to a point, then it sticks, like a table header.

🗣️ Say it in one line: Relative nudges and anchors, absolute uses the nearest positioned parent, fixed uses the screen, sticky switches on scroll.

Q5

rem vs em vs px vs %? How do you make a site responsive?

3–5 yrs
Show answer

🟢 In simple words: rem is relative to the page's base font size. Responsive means the layout bends to fit any screen, starting with mobile.

  • px: fixed size.
  • rem: relative to the root font size (usually 16px). Best for font sizes and spacing.
  • em: relative to the parent's font size, which can multiply when nested.
  • %, vw, vh: relative to the parent or the screen.

Responsive design means: start mobile-first, use flex/grid with wrapping, use max-width instead of a fixed width, add media queries at breakpoints, and include the viewport meta tag.

.cards { display: grid; gap: 1rem; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); }
@media (min-width: 768px) { .sidebar { display: block; } }

🗣️ Say it in one line: rem for sizes, mobile-first CSS, flexible grids and a few media queries.

Q6

What is semantic HTML and why does it matter?

3–5 yrs
Show answer

🟢 In simple words: Use tags that say what things are (button, nav, label). Screen readers, Google and keyboards understand them for free.

Semantic HTML uses tags that describe meaning: header, nav, main, article, button, label, instead of div everywhere.

It helps screen readers (accessibility), SEO, and gives keyboard support for free. For example, a real button works with Enter and Space, but a div with onClick doesn't.

🗣️ Say it in one line: Meaningful tags give accessibility, SEO and keyboard support for free.

↪️ Follow-up: What basic accessibility checks do you do? Alt text on images, a label for every input, enough colour contrast, everything usable by keyboard, and visible focus outlines.

Q7

localStorage vs sessionStorage vs cookies?

3–5 yrs🔥 Very common
Show answer

🟢 In simple words: localStorage keeps data in the browser, sessionStorage keeps it until the tab closes, and cookies travel to the server with every request.

  • localStorage: about 5 MB, stays until cleared, readable by any JavaScript on the page.
  • sessionStorage: same, but cleared when the tab closes.
  • Cookies: small (about 4 KB), sent to the server with every request, and can be HttpOnly (hidden from JavaScript), Secure and SameSite.

For auth tokens, an HttpOnly cookie is safer than localStorage, because an XSS attack can read localStorage.

🗣️ Say it in one line: Storage stays in the browser; cookies travel with requests, and HttpOnly cookies are safest for tokens.

Q8

What happens in the browser between getting HTML and showing the page?

5–8 yrs
Show answer

🟢 In simple words: The browser reads HTML and CSS, works out what's visible, calculates positions, then paints pixels.

🖼️ Picture it

This is the critical rendering path:

  • Parse HTML into the DOM and CSS into the CSSOM.
  • Combine them into the render tree (only visible elements).
  • Layout: calculate size and position.
  • Paint: fill pixels, then composite layers.

A <script> without defer blocks parsing, and CSS blocks rendering. That is why we use defer, load less CSS up front, and lazy-load images.

🗣️ Say it in one line: DOM plus CSSOM make the render tree, then layout, paint and composite.

↪️ Follow-up: Reflow vs repaint? Reflow recalculates layout (expensive, caused by size or position changes); repaint only redraws colours. Animate transform and opacity to avoid both.

Mock task 1: Build a header with the logo on the left and links on the right, which wraps nicely on mobile.

Show a sample answer

Use flexbox with justify-content: space-between and flex-wrap: wrap.

.header { display: flex; justify-content: space-between; align-items: center; flex-wrap: wrap; gap: 1rem; }

Mock task 2: A modal must sit over everything and stay centered. How?

Show a sample answer

A position: fixed; inset: 0 overlay using display: grid; place-items: center, a z-index above the page, focus moved into the modal, Escape to close, and role="dialog" with aria-modal="true".
