Frontend Interview: hard words, simply explained

60 words used in the answers, each in one or two simple lines. On the question pages, these words have a dotted underline; tap them to see the meaning.

JavaScript

Hoisting
JavaScript moves declarations to the top of their scope before running the code.
Temporal dead zone
The time before a let or const line runs, when using that variable throws an error.
Scope
Where a variable can be used. Block scope means only inside the nearest { }.
Closure
A function that remembers the variables from the place where it was created.
Call stack
The list of functions running right now. JavaScript finishes the top one first.
Event loop
The manager that gives JavaScript the next ready callback when it's free.
Microtask
A small urgent job (like a promise callback) that runs before timers.
Macrotask
A normal queued job, like a setTimeout callback.
Callback
A function you hand over to be called later.
Promise
An object for a result that will come later: success or failure.
Prototype
A hidden parent object that another object borrows properties from.
Mutation
Changing data in place instead of making a new copy.
Radix
The number base: 10 for normal numbers, 2 for binary.
Web Worker
A background thread in the browser for heavy work, so the page doesn't freeze.

TypeScript

Generic
A type with a blank you fill in later, like Box<Order>.
Union type
A type that can be one of several options, like "open" | "closed".
Discriminated union
A union where every option has a shared field (like status) that tells which one it is.
Narrowing
TypeScript working out a more exact type after an if-check.

HTML and CSS

Specificity
The score CSS uses to decide which rule wins.
Accessibility
Making a site usable for everyone, including people using screen readers or keyboards.
Screen reader
Software that reads the page aloud for people who can't see the screen.
DOM
The browser's live tree of the page's elements, which JavaScript can change.
Reflow
The browser recalculating positions and sizes after a change. It's costly.

React

Virtual DOM
React's light copy of the page in memory, used to find what changed.
Reconciliation
React comparing the new screen description with the old one.
Re-render
React running a component again to see if the screen should change.
Props
Inputs passed from a parent component to a child.
State
Data a component remembers, which redraws the screen when it changes.
Memoisation
Remembering a result so it isn't calculated again.
Prop drilling
Passing props through many layers that don't need them.
Hook
A use... function that gives a component state or other React features.
Batching
Combining several state updates into one redraw.
Dependency array
The list of values that decides when an effect runs again.
Race condition
A bug where the result depends on which thing finishes first.
Stale closure
A function that still sees old values from an earlier render.
Context
A React way to share a value with many components without passing props.
Provider
The component that holds a context value for everything below it.

React Query

Server state
Data that really lives on the server, and the app only keeps a copy of.
Cache
A saved copy of data, kept so it can be shown again quickly.
Invalidation
Marking cached data as old, so it gets fetched again.
Optimistic update
Showing the expected result before the server confirms it.
Mutation (React Query)
A request that changes data on the server: create, update or delete.

Performance

Lazy loading
Loading something only when it's needed.
Bundle
The JavaScript files your app is packed into for the browser.
Code splitting
Breaking the bundle into smaller files that load on demand.
Virtualise
Drawing only the rows visible on screen in a long list.

Security

XSS
Cross-Site Scripting: an attacker's script running on your page.
CSRF
A trick that makes your browser send a request with your cookies from another site.
CORS
A browser rule: a page can read another site's reply only if that site allows it.
Sanitise
Cleaning HTML to remove anything dangerous, like scripts.

Auth

Token
A signed digital pass that proves who you are to the API.
JWT
JSON Web Token: a signed pass with user details that anyone can read but nobody can change.
OIDC
OpenID Connect: a standard login layer on top of OAuth2.
PKCE
A safety check that protects the login code exchange in browser and mobile apps.
RBAC
Role-Based Access Control: what you can do depends on your role.
Interceptor (axios)
Code that runs on every request or response, like adding a token.

Interview

STAR method
Situation, Task, Action, Result: a simple way to tell a work story.
CTC
Cost To Company: your total yearly salary package.
Notice buyout
The new company pays your old company so you can leave before the notice period ends.
BGV
Background verification: checks of your past jobs, salary and documents.
