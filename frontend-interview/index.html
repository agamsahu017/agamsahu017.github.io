How interviews usually work in Delhi NCR

For 3–10 years of experience, service companies (like TCS, Infosys, Wipro, Tech Mahindra, Cognizant and Accenture) and product companies in Noida, Gurugram and Delhi usually follow a pattern like this. Many rounds are on video calls; some companies run weekend hiring drives.

RoundWhat happensHow to prepare
Recruiter / HR callNotice period, current and expected CTC, location (Noida, Gurugram, Delhi), office or hybrid, skills match.Keep exact numbers ready. Be honest: it's checked later.
Online test (sometimes)MCQs on JavaScript, React and CSS, plus 1–2 easy coding problems. More common in bulk or weekend hiring drives.Revise the JavaScript core and HTML/CSS modules.
Technical round 1 (L1)Concepts and live coding on a video call: closures, event loop, hooks, a small component or a debounce function.Do the mock tasks on each page out loud, with screen sharing.
Technical round 2 (L2) / client roundYour project in depth, scenarios (slow page, auth, RBAC, big forms), architecture choices. Some service-company projects add a round with the client.Prepare a 2-minute project story and one hard problem with numbers.
Managerial roundEstimates, deadlines, production issues, conflicts, leading juniors.Use STAR answers from the senior rounds module.
HR roundWhy switch, notice period, salary discussion, documents and background verification.Research the salary range first and give a range with reasons.

Every company, project and year is different. This is the common pattern we see in Noida, Gurugram and Delhi hiring for 3–10 years of experience, not an official process of any company. Kodivo is not linked to any company named here.

How to use these pages

  • Try first: read the question, answer out loud, then open the answer. Use "Show all answers" only for revision.
  • Say it in one line: every answer has a one-liner. Start with it in the interview, then explain.
  • Follow-ups: interviewers almost always ask one more question. Practise the follow-up too.
  • Use your project: after each answer, add "In my project, we used this for..." That is what makes an experienced answer.
  • Backend too? Full-stack roles get backend questions as well; see the Backend Interview series.
