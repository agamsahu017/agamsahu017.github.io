CS fundamentals glossaryCS fundamentals glossary

43 words from networks, DBMS, OS, OOPS, software engineering and aptitude, each in one or two simple lines.

Networks, DBMS, OS, OOPS, software engineering और aptitude के 43 शब्द, हर एक एक-दो आसान लाइनों में।

Computer NetworksComputer Networks

IP address
The address of a device on a network, like 142.250.183.14.Network पर किसी device का address, जैसे 142.250.183.14।
DNS
The internet's phonebook: turns a name like google.com into an IP address.Internet की phonebook: google.com जैसे नाम को IP address में बदलता है।
TCP
A protocol that delivers data reliably and in order, re-sending anything lost.एक protocol जो data को भरोसे से और सही क्रम में पहुँचाता है, खोया data दोबारा भेजता है।
UDP
A fast protocol with no delivery guarantee. Used for video calls, games and DNS.एक तेज़ protocol जिसमें पहुँचने की गारंटी नहीं। Video calls, games और DNS में इस्तेमाल।
Port
A number that tells which program on a computer should receive the data, like 443 for HTTPS.एक number जो बताता है कि computer का कौन-सा program data लेगा, जैसे HTTPS के लिए 443।
HTTP / HTTPS
The language of the web between browser and server. HTTPS is the encrypted version.Browser और server के बीच web की भाषा। HTTPS उसका encrypted रूप है।
TLS
The encryption that puts the S in HTTPS. It proves the site's identity with a certificate.वो encryption जिससे HTTPS में S आता है। यह certificate से site की पहचान साबित करता है।
Handshake
A few setup messages before real data, like TCP's SYN, SYN-ACK, ACK.असली data से पहले setup वाले कुछ messages, जैसे TCP का SYN, SYN-ACK, ACK।
Packet
A small piece of data sent over a network. Big data is split into many packets.Network पर भेजा गया data का छोटा टुकड़ा। बड़ा data कई packets में बँटता है।
Router
A device that forwards packets between networks, like your Wi-Fi router.एक device जो networks के बीच packets आगे भेजता है, जैसे आपका Wi-Fi router।
Latency
The delay for data to travel, usually in milliseconds.Data के पहुँचने में लगने वाली देरी, आमतौर पर milliseconds में।

DBMS and SQLDBMS और SQL

DBMS
Database Management System: software that stores and manages data, like MySQL or PostgreSQL.Database Management System: data रखने और संभालने वाला software, जैसे MySQL या PostgreSQL।
SQL
Structured Query Language: the language to read and change data in relational databases.Structured Query Language: relational databases में data पढ़ने और बदलने की भाषा।
Primary key
A column that uniquely identifies each row and can't be empty.एक column जो हर row को अलग पहचान देता है और ख़ाली नहीं हो सकता।
Foreign key
A column that points to the primary key of another table, linking the two.एक column जो दूसरी table की primary key की ओर इशारा करके दोनों को जोड़ता है।
JOIN
Combining rows from two tables using a related column.किसी जुड़े column से दो tables की rows को मिलाना।
NULL
"No value" or unknown. Not the same as 0 or an empty string."कोई value नहीं" या अनजान। 0 या ख़ाली string के बराबर नहीं।
Index
A lookup structure that makes searching a column fast, like a book's index.एक lookup structure जो column में ढूँढना तेज़ करता है, जैसे किताब का index।
Normalization
Organising tables so the same fact isn't stored in many places.Tables को ऐसे सजाना कि एक ही बात कई जगह न रखी जाए।
Transaction
A group of changes that succeed together or not at all.बदलावों का समूह जो या तो साथ में सफल हों या बिल्कुल न हों।
ACID
Atomicity, Consistency, Isolation, Durability: the promises of a reliable transaction.Atomicity, Consistency, Isolation, Durability: भरोसेमंद transaction के वादे।

Operating SystemsOperating Systems

Process
A running program, with its own memory.चलता हुआ program, अपनी अलग memory के साथ।
Thread
A worker inside a process. Threads of one process share its memory.Process के अंदर का एक worker। एक process के threads उसकी memory बाँटते हैं।
Context switch
The CPU saving one task's state and loading another's. It has a small cost.CPU का एक task की हालत save करके दूसरे की load करना। इसकी थोड़ी cost होती है।
Concurrency
Handling many tasks by switching between them, not necessarily at the same instant.बीच-बीच में switch करके कई tasks संभालना, ज़रूरी नहीं कि एक ही पल में।
Parallelism
Really running tasks at the same time on multiple CPU cores.कई CPU cores पर सच में एक ही समय tasks चलाना।
Race condition
A bug where the result depends on which task runs first, like two withdrawals overwriting each other.ऐसा bug जिसमें नतीजा इस पर निर्भर हो कि कौन-सा task पहले चला, जैसे दो withdrawals एक-दूसरे को overwrite कर दें।
Mutex / lock
Lets only one task enter a critical section at a time.एक बार में सिर्फ़ एक task को critical section में जाने देता है।
Deadlock
Two or more tasks waiting for each other forever.दो या ज़्यादा tasks हमेशा के लिए एक-दूसरे का इंतज़ार करते रहें।
Kernel
The core of the operating system that controls CPU, memory and devices.Operating system का मुख्य हिस्सा जो CPU, memory और devices को control करता है।

OOPSOOPS

Class
A blueprint for creating objects.Objects बनाने का नक़्शा (blueprint)।
Object
A real thing created from a class, with its own data.Class से बनी असली चीज़, अपने data के साथ।
Encapsulation
Keeping data private and changing it only through methods.Data को private रखना और सिर्फ़ methods से बदलना।
Abstraction
Showing only what's needed and hiding complex details.सिर्फ़ ज़रूरी चीज़ दिखाना और मुश्किल details छिपाना।
Inheritance
A class reusing another class's code: "a Car is a Vehicle".एक class का दूसरी class का code दोबारा इस्तेमाल करना: "Car एक Vehicle है"।
Polymorphism
One method name, different behaviour depending on the object.एक method का नाम, object के हिसाब से अलग व्यवहार।
Interface
A contract listing methods a class must provide.एक contract जो बताता है कि class को कौन-से methods देने ही होंगे।

Software EngineeringSoftware Engineering

SDLC
Software Development Life Cycle: plan, design, build, test, release, maintain.Software Development Life Cycle: plan, design, build, test, release, maintain।
Agile
Building software in small steps with frequent feedback, instead of one big plan.एक बड़े plan की जगह छोटे-छोटे steps और बार-बार feedback के साथ software बनाना।
STAR method
Situation, Task, Action, Result: a way to tell a story in interviews.Situation, Task, Action, Result: interview में कहानी बताने का तरीक़ा।

AptitudeAptitude

Cost price (CP)
The price at which something is bought.वो कीमत जिस पर चीज़ ख़रीदी गई।
Selling price (SP)
The price at which something is sold.वो कीमत जिस पर चीज़ बेची गई।
Marked price (MP)
The price printed on the tag, before any discount.Tag पर छपी कीमत, discount से पहले।
