Only cities with more than 1 studentसिर्फ़ 1 से ज़्यादा students वाली cities

SELECT city, COUNT(*) AS students
FROM students
GROUP BY city
HAVING COUNT(*) > 1;

WHERE vs HAVING (asked very often): WHERE filters rows before grouping. HAVING filters groups after grouping, so it can use COUNT, SUM and other totals.

WHERE vs HAVING (बहुत पूछा जाता है): WHERE grouping से पहले rows छाँटता है। HAVING grouping के बाद groups छाँटता है, इसलिए उसमें COUNT, SUM जैसे totals चलते हैं।

Order in which SQL runs: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT. That's why you can't use a SELECT alias inside WHERE in most databases.

SQL किस क्रम में चलता है: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT। इसीलिए ज़्यादातर databases में SELECT का alias WHERE में नहीं चलता।

LEFT JOIN: keep every row from the left tableLEFT JOIN: बाईं table की हर row रखो Beginnerशुरुआती

Dev hasn't joined any course. INNER JOIN drops him; LEFT JOIN keeps him with a count of 0.

Dev ने कोई course नहीं लिया। INNER JOIN उसे हटा देता है; LEFT JOIN उसे 0 count के साथ रखता है।

SELECT s.name, COUNT(e.course_id) AS courses
FROM students s
LEFT JOIN enrollments e ON e.student_id = s.id
GROUP BY s.id, s.name
ORDER BY s.name;

Use IS NULL, never = NULL. NULL means "unknown", so NULL = NULL is not true.

IS NULL लिखिए, = NULL कभी नहीं। NULL का मतलब "अनजान" है, इसलिए NULL = NULL true नहीं होता।

Method 2: DENSE_RANK (easy to change to Nth highest)Method 2: DENSE_RANK (Nth highest के लिए बदलना आसान) Senior levelSenior level

SELECT DISTINCT salary
FROM (
  SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
  FROM employees
) ranked
WHERE rnk = 2;

Result (1 row):नतीजा (1 rows):

salary
82,000

Two people earn 90,000, so the second highest distinct salary is 82,000. DENSE_RANK gives equal values the same rank without gaps (1, 1, 2…), unlike RANK (1, 1, 3…) and ROW_NUMBER (1, 2, 3…). Say this difference in the interview.

दो लोगों की salary 90,000 है, इसलिए दूसरी सबसे बड़ी अलग salary 82,000 है। DENSE_RANK बराबर values को एक ही rank देता है, बिना gap के (1, 1, 2…), जबकि RANK (1, 1, 3…) और ROW_NUMBER (1, 2, 3…)। Interview में यह फ़र्क़ बताइए।

⚠️ Common mistakesआम ग़लतियाँ
  • Using WHERE COUNT(*) > 1. Totals go in HAVING.WHERE COUNT(*) > 1 लिखना। Totals HAVING में जाते हैं।
  • Writing = NULL instead of IS NULL.IS NULL की जगह = NULL लिखना।
  • Using INNER JOIN when the question says "including students with no course".सवाल में "बिना course वाले students भी" हो, तब भी INNER JOIN लगाना।
  • Selecting a column that is neither in GROUP BY nor inside a total like COUNT or MAX.ऐसा column select करना जो न GROUP BY में हो, न COUNT या MAX जैसे total के अंदर।
📌 Remember these 3 thingsये 3 बातें याद रखिए
  1. Run order: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.चलने का क्रम: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT।
  2. WHERE filters rows; HAVING filters groups.WHERE rows छाँटता है; HAVING groups।
  3. INNER JOIN keeps matches only; LEFT JOIN keeps every left row (NULL if no match).INNER JOIN सिर्फ़ मेल रखता है; LEFT JOIN बाईं हर row रखता है (मेल न हो तो NULL)।
