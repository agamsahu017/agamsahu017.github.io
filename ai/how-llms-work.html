How ChatGPT and Claude workChatGPT और Claude कैसे काम करते हैं

⏱️ 25 min read + practice25 मिनट पढ़ाई + प्रैक्टिस🤖 AI🎯 Interview focusedइंटरव्यू के हिसाब से

In one line: An LLM writes one small piece of text (a token) at a time, choosing the most likely next piece based on everything before it.

एक लाइन में: LLM एक बार में text का एक छोटा टुकड़ा (token) लिखता है, पहले लिखी हर चीज़ देखकर सबसे संभावित अगला टुकड़ा चुनते हुए।

A very smart autocompleteएक बहुत समझदार autocomplete

Your phone keyboard suggests "morning" after "Good". An LLM does the same thing, but it is far better at it: it looks at everything written so far and picks the next piece of text, then the next, then the next, until the answer is complete.

आपका phone keyboard "Good" के बाद "morning" सुझाता है। LLM भी यही करता है, पर कहीं बेहतर: वो अब तक लिखा सब कुछ देखकर अगला टुकड़ा चुनता है, फिर अगला, फिर अगला, जब तक जवाब पूरा न हो।

This is why answers appear word by word in ChatGPT and Claude. That's streaming: you see each token as it is generated.

इसीलिए ChatGPT और Claude में जवाब शब्द-दर-शब्द आते हैं। यह streaming है: हर token बनते ही दिखता है।

Tokens: how AI reads textTokens: AI text कैसे पढ़ता है

LLMs don't read whole words. They read tokens: common words are one token, longer or rare words are split into pieces. In English, 100 tokens is roughly 75 words. Hindi and other languages often need more tokens for the same meaning.

LLMs पूरे शब्द नहीं पढ़ते। वो tokens पढ़ते हैं: आम शब्द एक token, लंबे या कम इस्तेमाल होने वाले शब्द टुकड़ों में। English में 100 tokens लगभग 75 शब्द होते हैं। Hindi और दूसरी भाषाओं में उसी मतलब के लिए अक्सर ज़्यादा tokens लगते हैं।

The context window: short-term memoryContext window: short-term memory

The context window is everything the model can see in one go: the instructions, the chat history, any documents you pasted, and the answer it is writing. Modern models have very large windows (hundreds of thousands of tokens or more), but it is still a limit.

Context window वो सब है जो model एक बार में देख सकता है: निर्देश, chat history, आपके paste किए documents, और जो जवाब वो लिख रहा है। आज के models की window बहुत बड़ी है (लाखों tokens या ज़्यादा), पर फिर भी एक सीमा है।

  • The model has no memory between separate API calls. A chatbot "remembers" because the app sends the whole conversation again each time.Model को अलग-अलग API calls के बीच कुछ याद नहीं रहता। Chatbot "याद" रखता है क्योंकि app हर बार पूरी बातचीत दोबारा भेजती है।
  • Very long chats get slower and costlier, and very old details can get less attention. Start a new chat for a new topic.बहुत लंबी chats धीमी और महँगी होती जाती हैं, और बहुत पुरानी बातों पर ध्यान कम हो सकता है। नए topic के लिए नई chat शुरू कीजिए।

Temperature: predictable or creative?Temperature: अनुमानित या creative?

For each next token, the model gives every option a probability. Temperature controls how it picks: low temperature almost always picks the top option (predictable), high temperature spreads the chances out (creative, but riskier).

हर अगले token के लिए model हर option को एक probability देता है। Temperature तय करता है कि वो कैसे चुने: कम temperature पर लगभग हमेशा सबसे ऊपर वाला option (अनुमानित), ज़्यादा temperature पर chances फैल जाते हैं (creative, पर ज़्यादा जोखिम)।

Note: some newer APIs, including current Claude models, no longer let you set temperature directly. There you steer behaviour with clear instructions and examples instead. The idea above still explains why the same prompt can give different answers.

ध्यान दें: कुछ नई APIs, जिनमें आज के Claude models भी हैं, अब temperature सीधे set नहीं करने देतीं। वहाँ आप साफ़ निर्देशों और examples से व्यवहार तय करते हैं। ऊपर वाला idea फिर भी समझाता है कि एक ही prompt से अलग-अलग जवाब क्यों आ सकते हैं।

Hallucination: confident but wrongHallucination: भरोसे से, पर ग़लत

Because an LLM predicts likely text rather than looking facts up, it can produce something that sounds right but isn't: a fake fee, a wrong date, a library function that doesn't exist.

LLM facts ढूँढने की जगह संभावित text predict करता है, इसलिए वो कुछ ऐसा बना सकता है जो सही लगे पर हो नहीं: नक़ली fee, ग़लत तारीख़, ऐसा library function जो है ही नहीं।

⚠️ Common mistakesआम ग़लतियाँ
  • Thinking the AI remembers you between separate chats or API calls.यह सोचना कि AI अलग-अलग chats या API calls के बीच आपको याद रखता है।
  • Pasting huge documents into every request and being surprised by the bill.हर request में बड़े documents paste करना और फिर bill देखकर हैरान होना।
  • Trusting exact numbers, dates or citations without checking.बिना check किए सटीक numbers, तारीख़ों या citations पर भरोसा करना।
📌 Remember these 3 thingsये 3 बातें याद रखिए
  1. AI reads and writes tokens, and you pay per token.AI tokens पढ़ता और लिखता है, और आप हर token का पैसा देते हैं।
  2. The context window is its short-term memory. It remembers nothing between separate calls.Context window उसकी short-term memory है। अलग-अलग calls के बीच उसे कुछ याद नहीं रहता।
  3. Low temperature = predictable, high = creative. Give real data to reduce hallucination.कम temperature = अनुमानित, ज़्यादा = creative। Hallucination कम करने के लिए असली data दीजिए।
