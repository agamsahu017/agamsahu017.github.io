How an AI app is builtAI app कैसे बनती है

Never put your API key in frontend code, a mobile app, or GitHub. Anyone can read it there and run up your bill. The browser calls your backend; your backend calls the AI API.

API key को कभी frontend code, mobile app या GitHub में मत डालिए। वहाँ कोई भी उसे पढ़कर आपका bill बढ़ा सकता है। Browser आपके backend को call करता है; आपका backend AI API को।

What is await? Asking the AI takes a few seconds. await simply means "wait here until the answer comes back, then continue". You'll see it before every AI call.

await क्या है? AI से पूछने में कुछ seconds लगते हैं। await का मतलब बस इतना है: "जवाब आने तक यहीं रुको, फिर आगे बढ़ो"। हर AI call से पहले यह दिखेगा।

Step 1: one small helper fileStep 1: एक छोटी helper file

Beginnerशुरुआती

Create ai.js and paste this. You write it once and reuse it everywhere. It hides the technical details, so your app code stays short and simple.

ai.js बनाइए और इसमें यह paste कीजिए। इसे एक बार लिखिए और हर जगह इस्तेमाल कीजिए। यह technical बातें छिपा देती है, जिससे आपकी app का code छोटा और आसान रहता है।

// ai.js - write once, reuse everywhere
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // reads your key from the .env file

function settings(messages, system) {
  return {
    model: "claude-opus-5-5",   // which AI model to use
    max_tokens: 16000,              // the longest answer we allow
    messages,                       // the conversation
    ...(system ? { system } : {}),  // optional rules for the AI
    // Safety net: if this model declines a request, the API tries a fallback model.
    betas: ["server-side-fallback-2026-07-01"],
    fallbacks: "default",
  };
}

function textOf(response) {
  return response.content.filter((b) => b.type === "text").map((b) => b.text).join("");
}

// Ask one question. Returns the answer as plain text.
export async function askAI(question, system) {
  const response = await client.beta.messages.create(settings([{ role: "user", content: question }], system));
  if (response.stop_reason === "refusal") return "Sorry, I can't help with that.";
  return textOf(response);
}

// Continue a conversation. "history" is an array that remembers the chat.
export async function chat(history, userText, system) {
  history.push({ role: "user", content: userText });
  const response = await client.beta.messages.create(settings(history, system));
  if (response.stop_reason === "refusal") {
    history.pop(); // forget the declined question so the chat can continue
    return "Sorry, I can't help with that.";
  }
  history.push({ role: "assistant", content: response.content }); // remember the reply
  return textOf(response);
}

// Print the answer word by word as it is written (like ChatGPT).
export async function streamAI(question, system) {
  const stream = client.beta.messages.stream({ ...settings([{ role: "user", content: question }], system), max_tokens: 64000 });
  stream.on("text", (text) => process.stdout.write(text));
  const message = await stream.finalMessage();
  console.log();
  return textOf(message);
}

You don't need to understand every line of ai.js today. Just know it gives you three easy functions: askAI, chat and streamAI.

आज ai.js की हर लाइन समझना ज़रूरी नहीं। बस इतना जानिए कि इससे आपको तीन आसान functions मिलते हैं: askAI, chat और streamAI।

Step 3: a chat that remembersStep 3: याद रखने वाली chat

Beginnerशुरुआती

The AI service doesn't remember anything between calls. To build a chat, we keep the conversation in an array called history and send it every time. The chat helper does this for you.

AI service calls के बीच कुछ याद नहीं रखती। Chat बनाने के लिए हम बातचीत को history नाम के array में रखते हैं और हर बार भेजते हैं। chat helper यह आपके लिए करता है।

// chat.js  →  node --env-file=.env chat.js
import { chat } from "./ai.js";

const RULES = "You are a friendly study buddy. Reply in 2-3 short lines.";
const history = []; // starts empty and grows with every message

console.log(await chat(history, "What is photosynthesis?", RULES));
console.log(await chat(history, "Give me one more example.", RULES)); // it knows what "more" means

Step 5: errors and costStep 5: errors और cost

Senior levelSenior level

Real apps must handle problems, like a wrong key or too many requests at once. Wrap the call in try / catch:

असली apps को problems संभालनी पड़ती हैं, जैसे ग़लत key या एक साथ बहुत ज़्यादा requests। Call को try / catch में रखिए:

import Anthropic from "@anthropic-ai/sdk";
import { askAI } from "./ai.js";

try {
  console.log(await askAI("Hello!"));
} catch (error) {
  if (error instanceof Anthropic.AuthenticationError) {
    console.error("Wrong API key. Check your .env file.");
  } else if (error instanceof Anthropic.RateLimitError) {
    console.error("Too many requests. Wait a little and retry.");
  } else if (error instanceof Anthropic.APIError) {
    console.error("API error", error.status, error.message);
  } else {
    throw error;
  }
}

Estimating cost: providers publish a price per million input tokens and per million output tokens. Cost = input tokens × input price + output tokens × output price. Output tokens usually cost several times more than input tokens, so asking for shorter answers saves money. Always check the provider's current pricing page.

Cost का अंदाज़ा: providers हर 10 लाख input tokens और हर 10 लाख output tokens की कीमत बताते हैं। Cost = input tokens × input कीमत + output tokens × output कीमत। Output tokens आमतौर पर input से कई गुना महँगे होते हैं, इसलिए छोटे जवाब माँगने से पैसे बचते हैं। Provider का मौजूदा pricing page हमेशा देखिए।

⚠️ Common mistakesआम ग़लतियाँ
  • Putting the API key in frontend JavaScript or pushing .env to GitHub.API key को frontend JavaScript में रखना या .env GitHub पर push करना।
  • Reading response.content[0].text without checking the block type or the stop reason.Block type या stop reason check किए बिना response.content[0].text पढ़ना।
  • Forgetting to send the chat history, then wondering why the bot "forgot".Chat history भेजना भूल जाना, फिर सोचना कि bot "भूल" क्यों गया।
  • No spending limit. Set a monthly budget in the provider's console.कोई spending limit नहीं। Provider के console में monthly budget set कीजिए।
📌 Remember these 3 thingsये 3 बातें याद रखिए
  1. The API key stays on your computer or server, in .env. Never in frontend code or GitHub.API key आपके computer या server पर, .env में रहती है। Frontend code या GitHub में कभी नहीं।
  2. The AI forgets everything between calls. A chat works because you send the history every time.AI calls के बीच सब भूल जाता है। Chat इसलिए चलती है क्योंकि आप हर बार history भेजते हैं।
  3. You pay per token. Shorter prompts and shorter answers cost less.आप हर token का पैसा देते हैं। छोटे prompts और छोटे जवाब सस्ते पड़ते हैं।

Exercise 1: Build a command-line "English to Hinglish" translator: the user types a sentence, the app prints the translation. Use a system prompt.Exercise 1: एक command-line "English से Hinglish" translator बनाइए: user sentence लिखे, app अनुवाद print करे। System prompt इस्तेमाल कीजिए।

Show a sample answerएक sample जवाब देखें
// translate.js  →  node --env-file=.env translate.js
import readline from "node:readline/promises"; // built into Node: reads what you type
import { askAI } from "./ai.js";

const RULES = "Translate the user's English sentence into natural, casual Hinglish " +
  "(Hindi written in English letters). Reply with the translation only.";
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });

while (true) {
  const text = await rl.question("English (or 'exit'): ");
  if (text.trim().toLowerCase() === "exit") break;
  console.log("Hinglish:", await askAI(text, RULES), "\n");
}
rl.close();
