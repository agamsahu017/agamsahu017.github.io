How an AI app is builtAI app कैसे बनती है

Never put your API key in frontend code, a mobile app, or GitHub. Anyone can read it there and run up your bill. The browser calls your backend; your backend calls the AI API.

API key को कभी frontend code, mobile app या GitHub में मत डालिए। वहाँ कोई भी उसे पढ़कर आपका bill बढ़ा सकता है। Browser आपके backend को call करता है; आपका backend AI API को।

Setup in 4 steps4 steps में setup

  1. Install Node.js (LTS) and create a folder for your project.Node.js (LTS) install कीजिए और project के लिए एक folder बनाइए।
  2. Get an API key from the Claude Console (console.anthropic.com) and add a small amount of credit.Claude Console (console.anthropic.com) से API key लीजिए और थोड़ा credit डालिए।
  3. Save the key in a .env file, and add .env to .gitignore so it never reaches GitHub.Key को .env file में रखिए, और .env को .gitignore में जोड़िए ताकि वो कभी GitHub पर न जाए।
  4. Install the official SDK (a ready-made library for calling the API).Official SDK install कीजिए (API call करने की तैयार library)।
# in your project folder
npm init -y
npm install @anthropic-ai/sdk

# .env  (never commit this file)
ANTHROPIC_API_KEY=sk-ant-...your-key...

Add "type": "module" to package.json so you can use import. Run files with node --env-file=.env app.js, which loads the key from .env.

package.json में "type": "module" जोड़िए ताकि import इस्तेमाल कर सकें। Files को node --env-file=.env app.js से चलाइए, जो .env से key लोड करता है।

Your first AI requestआपकी पहली AI request

Beginnerशुरुआती 
// app.js  →  run: node --env-file=.env app.js
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic(); // reads ANTHROPIC_API_KEY automatically

const response = await client.beta.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 16000,
  messages: [{ role: "user", content: "Explain what an API is to a 10-year-old." }],
  // Safety net: if this model declines a request, the API retries it on a
  // fallback model automatically.
  betas: ["server-side-fallback-2026-07-01"],
  fallbacks: "default",
});

if (response.stop_reason === "refusal") {
  console.log("The request was declined.");
} else {
  for (const block of response.content) {
    if (block.type === "text") console.log(block.text);
  }
}

console.log("Tokens used:", response.usage.input_tokens, "in,", response.usage.output_tokens, "out");

modelWhich AI model to useकौन-सा AI model इस्तेमाल करना है
max_tokensThe most tokens the answer may use (a safety cap)जवाब ज़्यादा से ज़्यादा कितने tokens ले सकता है (एक safety सीमा)

Add a system prompt and chat historySystem prompt और chat history जोड़ें

The API doesn't remember anything between calls. To build a chat, keep the conversation in an array and send it every time.

API calls के बीच कुछ याद नहीं रखती। Chat बनाने के लिए बातचीत को एक array में रखिए और हर बार भेजिए।

import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();
const SYSTEM = "You are a friendly study buddy for Class 10 students in India. " +
  "Explain simply, with Indian examples, in 3-5 short lines.";
const history = []; // the whole conversation, in order

async function chat(userText) {
  history.push({ role: "user", content: userText });

  const response = await client.beta.messages.create({
    model: "claude-opus-5-5",
    max_tokens: 16000,
    system: SYSTEM,
    messages: history,
    betas: ["server-side-fallback-2026-07-01"],
    fallbacks: "default",
  });

  if (response.stop_reason === "refusal") {
    history.pop(); // drop the declined question so the chat can continue
    return "Sorry, I can't help with that.";
  }
  history.push({ role: "assistant", content: response.content }); // keep the full reply
  return response.content.filter((b) => b.type === "text").map((b) => b.text).join("");
}

console.log(await chat("What is photosynthesis?"));
console.log(await chat("Give me one more example.")); // it knows what "more" refers to

Streaming: show the answer as it's writtenStreaming: जवाब लिखते-लिखते दिखाइए

Waiting 10 seconds for a full answer feels slow. Streaming shows each piece as soon as it's generated, like ChatGPT.

पूरे जवाब के लिए 10 seconds रुकना धीमा लगता है। Streaming हर टुकड़ा बनते ही दिखाता है, ChatGPT की तरह।

const stream = client.beta.messages.stream({
  model: "claude-opus-5-5",
  max_tokens: 64000,
  messages: [{ role: "user", content: "Write a short story about a robot in Lucknow." }],
  betas: ["server-side-fallback-2026-07-01"],
  fallbacks: "default",
});

stream.on("text", (text) => process.stdout.write(text)); // print as it arrives
const message = await stream.finalMessage();              // the complete message
console.log("\nOutput tokens:", message.usage.output_tokens);

Errors and costErrors और cost

try {
  const response = await client.messages.create({ /* ... */ });
} catch (error) {
  if (error instanceof Anthropic.AuthenticationError) {
    console.error("Wrong API key. Check your .env file.");
  } else if (error instanceof Anthropic.RateLimitError) {
    console.error("Too many requests. Wait a little and retry.");
  } else if (error instanceof Anthropic.APIError) {
    console.error("API error", error.status, error.message);
  } else {
    throw error;
  }
}

Estimating cost: providers publish a price per million input tokens and per million output tokens. Cost = input tokens × input price + output tokens × output price. Output tokens usually cost several times more than input tokens, so asking for shorter answers saves money. Always check the provider's current pricing page.

Cost का अंदाज़ा: providers हर 10 लाख input tokens और हर 10 लाख output tokens की कीमत बताते हैं। Cost = input tokens × input कीमत + output tokens × output कीमत। Output tokens आमतौर पर input से कई गुना महँगे होते हैं, इसलिए छोटे जवाब माँगने से पैसे बचते हैं। Provider का मौजूदा pricing page हमेशा देखिए।

⚠️ Common mistakesआम ग़लतियाँ
  • Putting the API key in frontend JavaScript or pushing .env to GitHub.API key को frontend JavaScript में रखना या .env GitHub पर push करना।
  • Reading response.content[0].text without checking the block type or the stop reason.Block type या stop reason check किए बिना response.content[0].text पढ़ना।
  • Forgetting to send the chat history, then wondering why the bot "forgot".Chat history भेजना भूल जाना, फिर सोचना कि bot "भूल" क्यों गया।
  • No spending limit. Set a monthly budget in the provider's console.कोई spending limit नहीं। Provider के console में monthly budget set कीजिए।

Practiceप्रैक्टिस

Exercise 1: Build a command-line "English to Hinglish" translator: the user types a sentence, the app prints the translation. Use a system prompt.Exercise 1: एक command-line "English से Hinglish" translator बनाइए: user sentence लिखे, app अनुवाद print करे। System prompt इस्तेमाल कीजिए।

Show a sample answerएक sample जवाब देखें
import readline from "node:readline/promises";
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });

while (true) {
  const text = await rl.question("English (or 'exit'): ");
  if (text.trim().toLowerCase() === "exit") break;

  const response = await client.beta.messages.create({
    model: "claude-opus-5-5",
    max_tokens: 1000,
    system: "Translate the user's English sentence into natural, casual Hinglish " +
      "(Hindi written in English letters). Reply with the translation only.",
    messages: [{ role: "user", content: text }],
    betas: ["server-side-fallback-2026-07-01"],
    fallbacks: "default",
  });

  const out = response.content.filter((b) => b.type === "text").map((b) => b.text).join("");
  console.log("Hinglish:", out, "\n");
}
rl.close();
