A simple formula for good promptsअच्छे prompts का आसान formula

Write to the AI like you are briefing a smart new colleague who knows nothing about your situation.

AI को ऐसे लिखिए जैसे किसी समझदार नए साथी को brief कर रहे हों जिसे आपकी situation के बारे में कुछ नहीं पता।

Show examples (few-shot) and ask for a formatExamples दिखाइए (few-shot) और format माँगिए

Showing 2–3 examples of what you want is often more powerful than describing it. This is called few-shot prompting.

आप क्या चाहते हैं उसके 2–3 examples दिखाना, उसे समझाने से अक्सर ज़्यादा असरदार होता है। इसे few-shot prompting कहते हैं।

Classify each customer message as FEES, TIMING or OTHER.

Message: "Kitni fees hai?"           → FEES
Message: "Sunday ko khula hai?"      → TIMING
Message: "Parking hai kya?"          → OTHER

Message: "Admission charges kya hain?" →

When your code will read the answer, ask for a strict format such as JSON, and say exactly which fields you need.

जब आपका code जवाब पढ़ेगा, तो JSON जैसा पक्का format माँगिए, और बताइए कि कौन-से fields चाहिए।

Extract the details from this message and reply with JSON only,
using exactly these keys: name, phone, course, preferred_time.
Use null for anything missing.

Message: "Hi, I'm Rohit, 9876543210, want JEE batch, evening better"

System prompts: rules for your AI appSystem prompts: आपकी AI app के नियम

In an app, the system prompt is written by the developer and applies to the whole conversation. Users don't see it. It sets the role, the rules, and what to do when unsure.

App में system prompt developer लिखता है और यह पूरी बातचीत पर लागू होता है। Users इसे नहीं देखते। यह role, नियम, और पक्का न होने पर क्या करना है, तय करता है।

You are the WhatsApp receptionist of CareWell Clinic, Lucknow.

Rules:
- Answer only questions about the clinic, using the information below.
- Never guess fees, timings or doctor names. If something isn't listed,
  say you'll confirm with the team.
- Never give medical advice. For emergencies, tell them to call 112.
- Reply in the customer's language (English, Hindi or Hinglish),
  in 2-4 short lines.

Clinic information:
- Consultation fee: ₹500
- Timings: Mon-Sat 9 AM-9 PM, Sunday 10 AM-1 PM

Explain the why. "Keep replies short, because customers read them on WhatsApp" works better than "SHORT REPLIES ONLY!!!". Modern models follow reasons well, and shouting isn't needed.

क्यों, यह बताइए। "जवाब छोटे रखो, क्योंकि customers WhatsApp पर पढ़ते हैं" ज़्यादा अच्छा काम करता है "SIRF CHHOTE JAWAB!!!" से। आज के models वजह समझकर अच्छे से मानते हैं, चिल्लाने की ज़रूरत नहीं।

Pro tipsPro tips

  • Ask it to think first for tricky problems: "Work through it step by step, then give the final answer."मुश्किल सवालों पर पहले सोचने को कहिए: "Step by step सोचो, फिर final जवाब दो।"
  • Separate data from instructions with tags like <document>…</document>, so the model doesn't confuse your text with your commands.Data को निर्देशों से अलग रखिए, <document>…</document> जैसे tags से, ताकि model आपके text और आदेशों में गड़बड़ न करे।
  • Iterate: if the answer is off, add the missing context and try again. Prompting is a conversation.दोहराइए: जवाब ठीक न हो, तो छूटा हुआ context जोड़कर फिर कोशिश कीजिए। Prompting एक बातचीत है।
  • Ask for options: "Give me 3 versions: formal, friendly and funny."Options माँगिए: "3 versions दो: formal, दोस्ताना और मज़ेदार।"
  • Ask it to check its work: "Before finishing, check the code for bugs and edge cases."अपना काम check करवाइए: "ख़त्म करने से पहले code में bugs और edge cases देखो।"
⚠️ Common mistakesआम ग़लतियाँ
  • One-line prompts with no context, then blaming the AI for generic answers.बिना context की एक लाइन वाला prompt, फिर generic जवाब के लिए AI को दोष देना।
  • Mixing many unrelated tasks in one prompt.एक prompt में कई अलग-अलग काम मिला देना।
  • Asking for JSON without saying the exact keys.Exact keys बताए बिना JSON माँगना।
  • Pasting private data (passwords, customer details) into public AI tools.Public AI tools में private data (passwords, customer details) paste करना।
📌 Remember these 3 thingsये 3 बातें याद रखिए
  1. Vague prompt = vague answer. Add context and details.धुंधला prompt = धुंधला जवाब। Context और details जोड़िए।
  2. Show 2–3 examples (few-shot) when you want a specific style or format.ख़ास style या format चाहिए, तो 2–3 examples (few-shot) दिखाइए।
  3. If your code reads the answer, ask for JSON with exact keys.अगर आपका code जवाब पढ़ेगा, तो exact keys वाला JSON माँगिए।

Exercise 1: Improve this prompt using the 5-part formula: "Make a resume for me."Exercise 1: 5-हिस्सों वाले formula से यह prompt बेहतर कीजिए: "Mera resume bana do."

Show a sample answerएक sample जवाब देखें
I'm a final-year B.Tech (CSE) student from Lucknow applying for
junior full stack developer roles. (context)

Write a one-page resume (task) using only these details: (details)
- Skills: JavaScript, React, Node.js, PostgreSQL, Git
- Projects: (1) Clinic appointment app with React + Node,
  (2) RAG chatbot over college notes
- Internship: 2 months at XYZ, built REST APIs

Format: plain text sections (Summary, Skills, Projects, Experience,
Education), bullet points starting with action verbs, numbers where
possible. (format)

It should pass a recruiter's 6-second scan. Don't invent anything that
isn't listed above. (quality bar)
