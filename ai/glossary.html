37 AI words, each explained in one or two simple lines. Use the search box to find a word quickly.

37 AI शब्द, हर एक का मतलब एक-दो आसान लाइनों में। किसी शब्द को जल्दी ढूँढने के लिए search box इस्तेमाल कीजिए।

AI basicsAI basics

AI (Artificial Intelligence)
Computers doing tasks that normally need human intelligence: understanding language, recognising images, making decisions.Computers का ऐसे काम करना जिनमें आमतौर पर इंसानी समझ लगती है: भाषा समझना, तस्वीरें पहचानना, फ़ैसले लेना।
Machine learning (ML)
Teaching computers by showing them many examples, instead of writing every rule by hand.हर नियम हाथ से लिखने की जगह, बहुत सारे examples दिखाकर computer को सिखाना।
Deep learning
Machine learning with large neural networks (many layers). Powers modern AI.बड़े neural networks (कई layers) वाली machine learning। आज की AI इसी से चलती है।
Neural network
A program made of many connected number-crunching units, loosely inspired by the brain.बहुत सारी जुड़ी हुई गणना करने वाली units से बना program, दिमाग़ से थोड़ा प्रेरित।
LLM (Large Language Model)
An AI trained on huge amounts of text to predict the next token. ChatGPT, Claude and Gemini are LLMs.बहुत सारे text पर trained AI जो अगला token predict करता है। ChatGPT, Claude और Gemini LLMs हैं।
Generative AI
AI that creates new content: text, images, code, audio or video.AI जो नया content बनाता है: text, images, code, audio या video।
Model
The trained AI itself: a large file of learned numbers (parameters) plus the code that runs it.Trained AI ख़ुद: सीखे हुए numbers (parameters) की बड़ी file और उसे चलाने वाला code।
Parameters
The numbers a model learned during training. More parameters usually means more capable, and more costly to run.Training में model के सीखे हुए numbers। ज़्यादा parameters आमतौर पर ज़्यादा क़ाबिल, और चलाने में ज़्यादा महँगा।
Training
Teaching a model by adjusting its parameters on huge data. Very expensive; done by AI companies.बहुत बड़े data पर parameters बदलकर model को सिखाना। बहुत महँगा; AI companies करती हैं।
Inference
Using a trained model to produce an answer. Every API call is inference.Trained model से जवाब निकलवाना। हर API call inference है।

How LLMs workLLMs कैसे काम करते हैं

Token
A small piece of text (part of a word) that an LLM reads and writes. Usage and cost are counted in tokens.Text का छोटा टुकड़ा (शब्द का हिस्सा) जिसे LLM पढ़ता और लिखता है। Usage और cost tokens में गिने जाते हैं।
Context window
How many tokens the model can see at once: instructions, chat history, documents and its answer together.Model एक बार में कितने tokens देख सकता है: निर्देश, chat history, documents और उसका जवाब मिलाकर।
Prompt
The input you give the model: your question, instructions and any data.Model को दिया गया input: आपका सवाल, निर्देश और कोई भी data।
System prompt
Instructions from the developer that set the AI's role and rules for the whole conversation.Developer के निर्देश जो पूरी बातचीत के लिए AI का role और नियम तय करते हैं।
Temperature
How random the word choice is. Low = predictable, high = creative.शब्द चुनने में कितना random-पन। कम = अनुमानित, ज़्यादा = creative।
Hallucination
When an AI confidently says something false or made up.जब AI पूरे भरोसे से कुछ ग़लत या मनगढ़ंत बोल दे।
Few-shot prompting
Showing the model a few examples of the input and output you want.Model को आपके चाहे गए input और output के कुछ examples दिखाना।

Building AI appsAI apps बनाना

Streaming
Showing the answer word by word as it's generated, instead of waiting for the whole answer.पूरे जवाब का इंतज़ार करने की जगह, जवाब को बनते-बनते शब्द-दर-शब्द दिखाना।
API key
A secret password your server uses to call an AI API. Never put it in frontend code or GitHub.एक secret password जिससे आपका server AI API call करता है। इसे कभी frontend code या GitHub में मत डालिए।
SDK
A ready-made library that makes calling an API easy in your language.एक तैयार library जो आपकी language में API call करना आसान बनाती है।
Embedding
A list of numbers that represents the meaning of a text. Similar meanings have similar numbers.Numbers की list जो text के मतलब को दिखाती है। मिलते-जुलते मतलब के numbers भी मिलते-जुलते होते हैं।
Vector
Another word for a list of numbers, like an embedding.Numbers की list का दूसरा नाम, जैसे embedding।
Cosine similarity
A score of how close two embeddings are in meaning: near 1 = very similar, near 0 = unrelated.दो embeddings मतलब में कितने पास हैं, उसका score: 1 के पास = बहुत मिलते-जुलते, 0 के पास = कोई संबंध नहीं।
Semantic search
Searching by meaning instead of exact words: "fees" also finds "charges".Exact शब्दों की जगह मतलब से search: "fees" से "charges" भी मिल जाता है।
Vector database
A database that stores embeddings and quickly finds the closest ones. Examples: pgvector, Pinecone, Qdrant.Database जो embeddings रखता है और सबसे पास वाले जल्दी ढूँढता है। जैसे pgvector, Pinecone, Qdrant।
pgvector
An extension that adds vector search to PostgreSQL.एक extension जो PostgreSQL में vector search जोड़ता है।
Chunking
Splitting long documents into small pieces before creating embeddings.Embeddings बनाने से पहले लंबे documents को छोटे टुकड़ों में बाँटना।
RAG
Retrieval-Augmented Generation: find relevant information first, then give it to the LLM with the question.Retrieval-Augmented Generation: पहले सही जानकारी ढूँढो, फिर सवाल के साथ LLM को दो।
Grounding
Making the AI answer only from given sources, so it doesn't make things up.AI को सिर्फ़ दिए गए sources से जवाब देने को कहना, ताकि वो बातें न बनाए।

AdvancedAdvanced

Tool calling
The model asks your code to run a function (like checking a database) and uses the result.Model आपके code से कोई function चलवाता है (जैसे database check करना) और नतीजा इस्तेमाल करता है।
AI agent
An AI that works in a loop: decides a step, uses tools, checks results, and repeats until the task is done.AI जो loop में काम करता है: step तय करता है, tools इस्तेमाल करता है, नतीजे देखता है, और काम पूरा होने तक दोहराता है।
MCP
Model Context Protocol: a standard way to connect AI apps to tools and data sources.Model Context Protocol: AI apps को tools और data sources से जोड़ने का standard तरीक़ा।
Fine-tuning
Further training a model on your examples to change its style or behaviour.अपने examples पर model को और train करना, उसका style या व्यवहार बदलने के लिए।
Evals
Tests for AI quality: a set of questions with expected answers, scored automatically.AI quality के tests: अपेक्षित जवाबों वाले सवालों का set, जो अपने आप score होता है।
Prompt injection
When text from a user or document tries to override the AI's instructions.जब user या document का text AI के निर्देशों को बदलने की कोशिश करे।
Prompt caching
Reusing the processed start of a long prompt across requests, so repeated calls are cheaper and faster.लंबे prompt की शुरुआत को requests के बीच दोबारा इस्तेमाल करना, ताकि बार-बार की calls सस्ती और तेज़ हों।
Transformer
The neural network design behind modern LLMs. It reads all tokens together and uses attention.आज के LLMs के पीछे का neural network design। यह सारे tokens साथ में पढ़ता है और attention इस्तेमाल करता है।
