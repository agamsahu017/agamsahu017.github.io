Classic ML terms (interview level)Classic ML शब्द (interview level)

⏱️ 18 min read + practice18 मिनट पढ़ाई + प्रैक्टिस🤖 AI🎯 Interview focusedइंटरव्यू के हिसाब से

In one line: ML has three types (supervised, unsupervised, reinforcement); supervised splits into classification (categories) and regression (numbers); and the network family is FNN, CNN for images, RNN/LSTM for sequences, and Transformers for modern NLP and LLMs.

एक लाइन में: ML के तीन प्रकार (supervised, unsupervised, reinforcement); supervised में classification (categories) और regression (numbers); और network परिवार है FNN, images के लिए CNN, sequences के लिए RNN/LSTM, और आधुनिक NLP व LLMs के लिए Transformers।

Know the common algorithm names (the idea matters, not the maths): logistic regression, decision tree, random forest, SVM, k-NN for classification; linear regression for regression. Interviewers want to hear that you know when each task type applies.

आम algorithm नाम जानिए (idea अहम है, maths नहीं): classification के लिए logistic regression, decision tree, random forest, SVM, k-NN; regression के लिए linear regression। Interviewers सुनना चाहते हैं कि कौन सा task कब लगता है, यह आप जानते हैं।

Common trap: a question that outputs a category is classification; one that outputs a number is regression. "Will this customer churn (yes/no)" = classification. "How much will they spend" = regression.

आम जाल: जो category दे वह classification है; जो number दे वह regression। "यह customer छोड़ेगा (हाँ/नहीं)" = classification। "कितना ख़र्च करेगा" = regression।

Unsupervised: finding patternsUnsupervised: patterns ढूँढना

Beginnerशुरुआती
  • Clustering: group similar items with no labels (k-means, hierarchical). Example: customer segments.Clustering: बिना labels मिलते-जुलते items के समूह (k-means, hierarchical)। उदाहरण: customer segments।
  • Dimensionality reduction (PCA): squeeze many features into a few, to simplify or visualise.Dimensionality reduction (PCA): कई features को कुछ में समेटना, सरल करने या देखने के लिए।
  • Anomaly / outlier detection: find the odd ones out, like fraud or faulty parts.Anomaly / outlier detection: अलग दिखने वाले ढूँढना, जैसे fraud या ख़राब parts।
  • Association: "people who buy X also buy Y" (market-basket rules).Association: "जो X ख़रीदते हैं वे Y भी" (market-basket rules)।

The key link for your interviews: today's LLMs are Transformers. CNNs still lead for images; RNN/LSTM are mostly legacy for text now, replaced by Transformers.

आपके interviews के लिए अहम कड़ी: आज के LLMs Transformers हैं। Images के लिए CNNs अब भी आगे; text के लिए RNN/LSTM अब ज़्यादातर पुराने, Transformers ने जगह ले ली।

Concepts interviewers loveInterviewers के पसंदीदा concepts

Senior levelSenior level
  • Overfitting vs underfitting: overfitting is memorising the training data (great on it, poor on new data); underfitting is too simple to learn the pattern. Fix overfitting with more data, regularisation or a simpler model.Overfitting vs underfitting: overfitting यानी training data रट लेना (उस पर बढ़िया, नए data पर ख़राब); underfitting यानी pattern सीखने के लिए बहुत सरल। Overfitting को ज़्यादा data, regularisation या सरल model से ठीक कीजिए।
  • Train / validation / test split: never test on data you trained on, or your score is a lie.Train / validation / test split: जिस data पर train किया उसी पर test मत कीजिए, वरना score झूठा है।
  • Loss function: a number that measures how wrong the model is; training lowers it, usually with gradient descent.Loss function: एक number जो बताता है model कितना ग़लत है; training इसे घटाती है, आम तौर पर gradient descent से।
  • Features and labels: features are the inputs; the label is the correct answer you want to predict.Features और labels: features input हैं; label वह सही जवाब है जो predict करना है।
  • NLP = teaching computers to understand language; Computer vision = teaching them to understand images.NLP = computers को भाषा समझाना; Computer vision = उन्हें images समझाना।

As an AI app developer (LLMs, RAG, agents) you usually won't train these models yourself, but interviewers check that you know the vocabulary. Be solid on the three types, classification vs regression, and the network family. Deep maths is for ML and data-science roles.

एक AI app developer (LLMs, RAG, agents) के तौर पर आप आम तौर पर ये models ख़ुद train नहीं करेंगे, पर interviewers देखते हैं कि आप शब्दावली जानते हैं। तीन प्रकार, classification vs regression, और network परिवार पक्के रखिए। गहरी maths ML और data-science roles के लिए है।

⚠️ Common mistakesआम ग़लतियाँ
  • Confusing classification (categories) with regression (numbers).Classification (categories) और regression (numbers) को गड्ड-मड्ड करना।
  • Saying LLMs are RNNs. Modern LLMs are Transformers.यह कहना कि LLMs RNN हैं। आधुनिक LLMs Transformers हैं।
  • Mixing up supervised (has labels) and unsupervised (no labels).Supervised (labels हैं) और unsupervised (labels नहीं) को मिला देना।

For networks, CNNs handle images, RNNs and LSTMs handle sequences, and Transformers power modern NLP and LLMs."

🎤 Interview line: "ML has three types: supervised learns from labelled data for classification or regression, unsupervised finds patterns like clusters, and reinforcement learns from rewards. For networks, CNNs handle images, RNNs and LSTMs handle sequences, and Transformers power modern NLP and LLMs."

  2. Classification = categories; regression = numbers.Classification = categories; regression = numbers।
  3. Unsupervised: clustering, dimensionality reduction, anomaly detection, association.Unsupervised: clustering, dimensionality reduction, anomaly detection, association।

Practiceप्रैक्टिस

Exercise 1: For each, say classification, regression or clustering: (a) predict tomorrow's temperature, (b) decide if an email is spam, (c) group shoppers into similar segments with no labels.Exercise 1: हर एक के लिए बताइए classification, regression या clustering: (a) कल का तापमान predict करना, (b) तय करना कि email spam है, (c) बिना labels shoppers को मिलते-जुलते segments में बाँटना।

Show a sample answerएक sample जवाब देखें

(a) Regression — the output is a number. (b) Classification — the output is a category (spam or not). (c) Clustering — unsupervised, grouping similar items with no labels.

(a) Regression — output एक number है। (b) Classification — output एक category है (spam या नहीं)। (c) Clustering — unsupervised, बिना labels मिलते-जुलते items के समूह।

Exercise 2: An interviewer asks: "Are LLMs RNNs?" Answer in one or two lines.Exercise 2: Interviewer पूछता है: "क्या LLMs RNN हैं?" एक-दो line में जवाब दीजिए।

Show a sample answerएक sample जवाब देखें

No. Modern LLMs are Transformers, not RNNs. RNNs and LSTMs were used for text earlier, but Transformers replaced them because attention handles long context and trains in parallel, which is what makes today's large language models possible.

नहीं। आधुनिक LLMs Transformers हैं, RNN नहीं। पहले text के लिए RNN और LSTM इस्तेमाल होते थे, पर Transformers ने उनकी जगह ले ली क्योंकि attention लंबा context संभालता है और parallel में train होता है, जिससे आज के बड़े language models संभव हैं।
