Level 1: AI Basics

In one line

An LLM is a very smart auto-complete → it reads tokens → it can only see a fixed amount of text at once (context window) → you send it a prompt → the system prompt gives it fixed rules → temperature controls how creative it is → a confident wrong answer is a hallucination → making an answer is called inference.

1. LLM (Large Language Model)

A program that has read a huge amount of books, websites and code, and learned to guess the next word (token).

  • Like your phone keyboard that suggests "morning" after "Good", but strong enough to write full emails, code and answers.
  • Examples: ChatGPT, Claude, Gemini.

🎤 "An LLM is a model trained on a huge amount of text to guess the next token. That is how it writes text, code and answers."

2. Token

AI reads tokens (small pieces of words), not full words.

  • "Hello" = 1 token. "Unbelievable" = "Un" + "believ" + "able" = 3 tokens.
  • In English, 1 token is about ¾ of a word. Hindi uses more tokens.
  • You pay for AI APIs by the token (tokens you send + tokens you get back).

Example: a taxi meter charges per kilometre. AI APIs charge per token.

🎤 "Tokens are the small units an LLM reads. Price, speed and limits are all counted in tokens."

3. Context window

The AI's short-term memory: how many tokens it can see at one time.

  • Like a one-page cheat sheet. When it is full, old text falls off. That is why very long chats "forget" the start.
  • New models can see hundreds of thousands of tokens.

🎤 "The context window is the most tokens the model can see at once: the prompt, the chat history and the answer together."

4. Prompt

The message you send to the AI.

  • ❌ "Write an email"
  • ✅ "Write a polite 5-line email to a clinic owner offering a free AI chatbot demo"
  • A clearer prompt gives a better answer. This skill is called prompt engineering.

Example: telling a tailor "make a shirt" vs "make a white cotton shirt, size 40, full sleeves, ready by Friday". The second one gets you what you want.

5. System prompt

Fixed instructions written by the developer. The user does not see them, but the AI always follows them.

You are the receptionist of CareWell Clinic.
Only answer questions about the clinic. Always be polite.
Fee: ₹400. Timing: 9 AM–9 PM. Never give medical advice.

Example: the shop owner's instructions to a new salesman before the shop opens. Customers never see them, but he follows them all day.

🎤 "The system prompt sets the model's role, rules and behaviour. The developer writes it, not the user."

6. Temperature

The creativity knob (from 0 to about 1).

Temperature What happens Use it for
Low (0) Same, safe answers every time Support bots, reading data from documents, code
High (about 1) New and different answers each time Marketing ideas, captions, stories

Example: a bank cashier (low temperature) must give the same exact answer every time. A copywriter (high temperature) should give a new idea every time.

7. Hallucination

When the AI says something wrong but sounds sure.

  • Why: the LLM guesses the most likely next word. It does not check facts.
  • Example: a student who didn't study but writes a confident, long answer in the exam anyway.
  • Fix: give it the right data (RAG), tell it "If you don't know, say so", use low temperature, and check the output.

🎤 "Hallucination is when the model writes something that sounds right but is false. We reduce it with RAG, clear rules, low temperature and checks."

8. Inference

When the AI makes an answer.

  • Training = a student studying for years (AI companies do this, it costs crores).
  • Inference = the student writing answers in the exam (you call the API, and each call costs a little).
  • As a developer, you use inference, not training.

Interview questions (answer out loud)

  1. What is an LLM, and how does it write text?
  2. What is a token, and why does it matter for cost?
  3. What happens when a chat is longer than the context window?
  4. What is the difference between a system prompt and a user prompt?
  5. Which temperature would you use for a customer support bot, and why?
  6. What is hallucination, and how do you reduce it in a live app?
  7. What is the difference between training and inference?

Quiz

  1. High or low temperature for a clinic bot? Why? → Low, because answers like fees must be the same and correct every time.
  2. How are AI APIs billed? → By tokens (sent + received).
  3. The bot told a customer the wrong fee. What is this called, and how do you stop it? → Hallucination. Use RAG with the real clinic data, a system prompt rule to say "I'll confirm" when unsure, and low temperature.

Level 1: AI की Basics

एक line में

LLM एक बहुत समझदार auto-complete है → यह tokens पढ़ता है → एक बार में तय मात्रा का text ही देख सकता है (context window) → आप इसे prompt भेजते हो → system prompt इसे पक्के rules देता है → temperature तय करता है कि यह कितना creative होगा → भरोसे से दिया गया गलत जवाब hallucination है → जवाब बनाने को inference कहते हैं।

1. LLM (Large Language Model)

एक program जिसने बहुत सारी किताबें, websites और code पढ़ा है, और अगला शब्द (token) guess करना सीख लिया है।

  • जैसे आपका phone keyboard "Good" के बाद "morning" suggest करता है, बस इतना ताक़तवर कि पूरे emails, code और जवाब लिख दे।
  • उदाहरण: ChatGPT, Claude, Gemini।

🎤 "An LLM is a model trained on a huge amount of text to guess the next token. That is how it writes text, code and answers."

2. Token

AI पूरे शब्द नहीं, tokens (शब्दों के छोटे टुकड़े) पढ़ता है।

  • "Hello" = 1 token। "Unbelievable" = "Un" + "believ" + "able" = 3 tokens।
  • English में 1 token लगभग ¾ शब्द होता है। Hindi में ज़्यादा tokens लगते हैं।
  • AI APIs का पैसा tokens के हिसाब से लगता है (भेजे गए tokens + वापस आए tokens)।

उदाहरण: taxi का meter: किलोमीटर के हिसाब से पैसा। यहाँ tokens के हिसाब से।

🎤 "Tokens are the small units an LLM reads. Price, speed and limits are all counted in tokens."

3. Context window

AI की short-term memory: एक बार में यह कितने tokens देख सकता है।

  • एक page की cheat sheet जैसा। भर जाए तो पुराना text गिर जाता है। इसीलिए बहुत लंबी chat में AI शुरुआत "भूल" जाता है।
  • नए models लाखों tokens तक देख सकते हैं।

🎤 "The context window is the most tokens the model can see at once: the prompt, the chat history and the answer together."

4. Prompt

वह message जो आप AI को भेजते हो।

  • ❌ "Write an email"
  • ✅ "Clinic के मालिक को free AI chatbot demo offer करते हुए 5 lines का विनम्र email लिखो"
  • Prompt जितना साफ़, जवाब उतना अच्छा। इस skill को prompt engineering कहते हैं।

उदाहरण: दर्ज़ी से "shirt बना दो" कहना vs "सफ़ेद cotton shirt, size 40, full sleeves, शुक्रवार तक"। दूसरे में वही मिलेगा जो चाहिए।

5. System prompt

Developer के लिखे पक्के निर्देश। User इन्हें नहीं देखता, पर AI हमेशा इन्हें मानता है।

You are the receptionist of CareWell Clinic.
Only answer questions about the clinic. Always be polite.
Fee: ₹400. Timing: 9 AM–9 PM. Never give medical advice.

उदाहरण: दुकान खुलने से पहले मालिक का नए salesman को समझाना। Customers को ये बातें नहीं दिखतीं, पर वह पूरा दिन इन्हें मानता है।

🎤 "The system prompt sets the model's role, rules and behaviour. The developer writes it, not the user."

6. Temperature

Creativity का knob (0 से लगभग 1 तक)।

Temperatureक्या होता हैकहाँ इस्तेमाल करें
Low (0)हर बार एक जैसे, सुरक्षित जवाबSupport bots, documents से data निकालना, code
High (लगभग 1)हर बार नए और अलग जवाबMarketing ideas, captions, कहानियाँ

उदाहरण: bank cashier (low temperature) को हर बार बिल्कुल वही सही जवाब देना है। Ad बनाने वाला (high temperature) हर बार नया idea दे।

7. Hallucination

जब AI गलत बात पूरे भरोसे से बोलता है।

  • क्यों: LLM सबसे संभावित अगला शब्द guess करता है। वह facts check नहीं करता।
  • उदाहरण: वह student जिसने पढ़ाई नहीं की, फिर भी exam में पूरे भरोसे से लंबा जवाब लिख आया।
  • इलाज: सही data दो (RAG), कहो "पता न हो तो बोल दो", temperature कम रखो, और output check करो।

🎤 "Hallucination is when the model writes something that sounds right but is false. We reduce it with RAG, clear rules, low temperature and checks."

8. Inference

जब AI जवाब बनाता है।

  • Training = student का सालों पढ़ाई करना (AI companies करती हैं, करोड़ों का खर्च)।
  • Inference = student का exam में जवाब लिखना (आप API call करते हो, हर call पर थोड़ा खर्च)।
  • Developer के रूप में आप inference इस्तेमाल करते हो, training नहीं।

  2. What is a token, and why does it matter for cost?
  3. What happens when a chat is longer than the context window?
  4. What is the difference between a system prompt and a user prompt?
  5. Which temperature would you use for a customer support bot, and why?
  6. What is hallucination, and how do you reduce it in a live app?
  7. What is the difference between training and inference?

Quiz

  1. Clinic bot के लिए high या low temperature? क्यों? → Low, क्योंकि fees जैसे जवाब हर बार एक जैसे और सही होने चाहिए।
  2. AI APIs का bill कैसे बनता है? → Tokens के हिसाब से (भेजे + वापस आए)।
  3. Bot ने customer को गलत fee बता दी। इसे क्या कहते हैं, और कैसे रोकोगे? → Hallucination। Clinic के असली data के साथ RAG, system prompt में rule कि पक्का न हो तो "confirm करके बताता हूँ" बोले, और low temperature।
