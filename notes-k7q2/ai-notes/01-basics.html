Level 1: AI Basics

One-line summary

An LLM is a smart auto-complete → it reads tokens → its memory is the context window → you give it a prompt → the system prompt sets its rules → temperature controls creativity → a confident wrong answer is a hallucination → generating the answer is inference.

1. LLM (Large Language Model)

A very well-read "auto-complete". It learned from huge amounts of books, websites and code to predict the next word (token).

  • Like your phone keyboard suggesting "morning" after "Good", but smart enough to write whole emails, code and answers.
  • Examples: ChatGPT, Claude, Gemini.

🎤 "An LLM is a neural network trained on huge amounts of text to predict the next token. That's how it generates text, code and answers."

2. Token

AI reads tokens (pieces of words), not words.

  • "Hello" = 1 token; "Unbelievable" ≈ "Un" + "believ" + "able" = 3 tokens
  • English: about 1 token ≈ ¾ word. Hindi uses more tokens.
  • API billing is per token (input + output).

🎤 "Tokens are the units LLMs process. Pricing, speed and limits are all measured in tokens."

3. Context window

The AI's short-term memory: how many tokens it can see at once.

  • Like a one-page cheat sheet. When it's full, old content drops off, which is why very long chats "forget" the start.
  • Modern models: hundreds of thousands of tokens or more.

🎤 "The context window is the maximum number of tokens the model can consider at once: the prompt, the history and the response together."

4. Prompt

What you send to the AI.

  • ❌ "Write an email"
  • ✅ "Write a polite 5-line email to a clinic owner offering a free AI chatbot demo, in Hinglish"
  • The clearer the prompt, the better the answer. This skill is prompt engineering.

5. System prompt

Permanent instructions set by the developer. The user doesn't see them, but the AI always follows them.

You are the receptionist of CareWell Clinic.
Only answer questions about the clinic. Always be polite.
Fee: ₹400. Timing: 9 AM–9 PM. Never give medical advice.

🎤 "The system prompt defines the model's role, rules and behaviour. It's set by the developer, not the end user."

6. Temperature

The creativity knob (0 to ~1).

Temperature Behaviour Use
Low (0) Same, safe, predictable answers Support bots, data extraction, code
High (~1) Creative, varied answers Marketing ideas, captions, stories

7. Hallucination

When the AI confidently says something false.

  • Why: the LLM predicts the likely next word. It doesn't check facts.
  • Fix: give it the right data (RAG), tell it "If you don't know, say so", use low temperature, and validate outputs.

🎤 "Hallucination is when the model generates plausible but false information. We reduce it with RAG, clear instructions, low temperature and validation."

8. Inference

The process of the AI generating an answer.

  • Training = a student studying for years (AI companies do this, it costs crores)
  • Inference = writing answers in the exam (you call the API, and each call costs a little)
  • As a developer you use inference, not training.

Interview questions (answer out loud)

  1. What is an LLM, and how does it generate text?
  2. What is a token, and why does it matter for cost?
  3. What happens when a conversation exceeds the context window?
  4. Difference between a system prompt and a user prompt?
  5. Which temperature would you use for a customer-support bot, and why?
  6. What is hallucination, and how do you reduce it in production?
  7. Difference between training and inference?

Quiz

  1. High or low temperature for a clinic bot? Why? → Low, because answers like fees must be consistent and accurate.
  2. What is AI API billing based on? → Tokens (input + output).
  3. The bot gave the wrong fee. What is it called, and how do you prevent it? → Hallucination. Use RAG with real clinic data, a system prompt rule to say "I'll confirm" when unsure, and low temperature.
