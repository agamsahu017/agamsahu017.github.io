How to solve any coding problemकिसी भी coding सवाल को कैसे हल करें

Stuck on an empty screen? Follow these 5 steps every time.

ख़ाली screen पर अटक गए? हर बार ये 5 steps follow कीजिए।

  1. Understand. Read the problem twice. Say in your own words what goes in and what must come out.समझो। सवाल दो बार पढ़ो। अपने शब्दों में बोलो कि input क्या है और output क्या चाहिए।
  2. Example by hand. Take a small example and solve it on paper, without code. Notice what steps you did.हाथ से example। एक छोटा example लो और बिना code के काग़ज़ पर हल करो। देखो तुमने कौन-से steps किए।
  3. Brute force first. Write the simplest solution that works, even if it is slow. A working slow answer beats a broken fast one.पहले brute force। सबसे आसान solution लिखो जो चले, भले धीमा हो। चलने वाला धीमा जवाब, टूटे हुए तेज़ जवाब से बेहतर है।
  4. Improve. Ask: "am I repeating work?" A hash map, two pointers or sorting often removes a loop.बेहतर करो। पूछो: "क्या मैं काम दोहरा रहा हूँ?" Hash map, two pointers या sorting से अक्सर एक loop हट जाता है।
  5. Test. Dry run your code on the example, then on edge cases: empty input, one item, duplicates, negatives.Test करो। Example पर code का dry run करो, फिर edge cases पर: ख़ाली input, एक item, duplicates, negatives।
