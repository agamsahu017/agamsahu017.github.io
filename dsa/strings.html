A string is an array of charactersString, characters का एक array है

The word "hello" is like an array: h e l l o, with indexes 0 to 4. You can read s[0] and s.length, just like an array.

शब्द "hello" एक array जैसा है: h e l l o, index 0 से 4 तक। आप s[0] और s.length पढ़ सकते हैं, बिल्कुल array की तरह।

Big difference: in JavaScript, strings are immutable. You can't change one letter in place. Every change creates a new string.

बड़ा फ़र्क़: JavaScript में strings immutable होती हैं। आप एक अक्षर सीधे नहीं बदल सकते। हर बदलाव से एक नई string बनती है।

let s = "hello";
s[0] = "j";           // no change (in strict mode: TypeError)
console.log(s);       // "hello"

s = "j" + s.slice(1); // build a new string instead
console.log(s);       // "jello"

// Need many changes? Turn it into an array, change it, then join.
const chars = s.split("");  // ["j", "e", "l", "l", "o"]
chars[0] = "y";
console.log(chars.join("")); // "yello"

Pattern 1: Two pointers (palindrome)Pattern 1: Two pointers (palindrome)

Warm-up: reverse with two pointersWarm-up: two pointers से उल्टा करना Beginnerशुरुआती

LeetCode's Reverse String gives you an array of characters. Swap the first and last, then move both pointers inwards.

LeetCode का Reverse String आपको characters का array देता है। पहला और आख़िरी swap करो, फिर दोनों pointers अंदर की ओर बढ़ाओ।

// O(n) time, O(1) extra space
function reverseString(s) {
  let left = 0;
  let right = s.length - 1;
  while (left < right) {
    [s[left], s[right]] = [s[right], s[left]]; // swap
    left++;
    right--;
  }
  return s;
}

reverseString(["h", "e", "l", "l", "o"]); // ["o", "l", "l", "e", "h"]

Now: is it a palindrome?अब: क्या यह palindrome है? Beginnerशुरुआती

A palindrome reads the same forwards and backwards, like level or madam. Put one pointer at the start and one at the end, compare, and move them towards the middle.

Palindrome आगे से और पीछे से एक जैसा पढ़ा जाता है, जैसे level या madam। एक pointer शुरुआत में और एक आख़िर में रखो, compare करो, और दोनों को बीच की ओर बढ़ाओ।

Try it: is it a palindrome?ख़ुद देखें: क्या यह palindrome है?
Type a word and press Check. Try racecar, level or hello.कोई शब्द लिखें और Check दबाएँ। racecar, level या hello आज़माएँ।
// Valid Palindrome: ignore spaces, symbols and capital letters
// O(n) time, O(1) extra space
function isPalindrome(s) {
  const isAlnum = (c) => /[a-z0-9]/i.test(c);
  let left = 0;
  let right = s.length - 1;
  while (left < right) {
    while (left < right && !isAlnum(s[left])) left++;   // skip symbols
    while (left < right && !isAlnum(s[right])) right--;
    if (s[left].toLowerCase() !== s[right].toLowerCase()) return false;
    left++;
    right--;
  }
  return true;
}

isPalindrome("A man, a plan, a canal: Panama"); // true

Pattern 2: Frequency count (anagram)Pattern 2: Frequency count (anagram)

Beginnerशुरुआती

Two words are anagrams if they use the same letters the same number of times, like listen and silent. Count letters in the first word (+1), subtract letters of the second (−1). If every count ends at 0, they are anagrams.

दो शब्द anagram हैं अगर उनमें वही अक्षर उतनी ही बार आएँ, जैसे listen और silent। पहले शब्द के अक्षर गिनो (+1), दूसरे के घटाओ (−1)। अगर हर count आख़िर में 0 हो, तो वो anagram हैं।

Try it: letter countsख़ुद देखें: अक्षरों की गिनती
// Valid Anagram: O(n) time, O(1) space (only 26 letters)
function isAnagram(s, t) {
  if (s.length !== t.length) return false;
  const count = new Array(26).fill(0);
  for (let i = 0; i < s.length; i++) {
    count[s.charCodeAt(i) - 97]++; // 'a' is 97
    count[t.charCodeAt(i) - 97]--;
  }
  return count.every((c) => c === 0);
}

isAnagram("listen", "silent"); // true
isAnagram("rat", "car");       // false

The same idea solves First Unique Character: count every letter first, then find the first letter whose count is 1.

यही idea First Unique Character भी हल करता है: पहले हर अक्षर गिनो, फिर वो पहला अक्षर ढूँढो जिसका count 1 हो।

function firstUniqChar(s) {
  const count = new Map();
  for (const c of s) count.set(c, (count.get(c) || 0) + 1);
  for (let i = 0; i < s.length; i++) {
    if (count.get(s[i]) === 1) return i;
  }
  return -1;
}

firstUniqChar("leetcode"); // 0 ("l")

Pattern 3: Sliding window (preview)Pattern 3: Sliding window (झलक)

Next level · optional on first readNext level · पहली बार में optional

Longest Substring Without Repeating Characters is one of the most asked string questions. Keep a "window" of characters with no repeats. Grow it from the right; when a repeat appears, shrink it from the left.

Longest Substring Without Repeating Characters सबसे ज़्यादा पूछे जाने वाले string सवालों में से है। बिना repeat वाले characters की एक "window" रखो। उसे दाईं ओर से बढ़ाओ; repeat आए तो बाईं ओर से छोटा करो।

// O(n) time, O(k) space (k = different characters)
function lengthOfLongestSubstring(s) {
  const lastSeen = new Map(); // character -> last index
  let left = 0;
  let best = 0;
  for (let right = 0; right < s.length; right++) {
    const c = s[right];
    if (lastSeen.has(c) && lastSeen.get(c) >= left) {
      left = lastSeen.get(c) + 1; // jump past the repeat
    }
    lastSeen.set(c, right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}

lengthOfLongestSubstring("abcabcbb"); // 3 ("abc")

Don't worry if this feels hard. Sliding window gets its own full module later. For now, just notice the idea: two pointers that form a window.

अगर यह मुश्किल लगे तो चिंता मत कीजिए। Sliding window का बाद में पूरा अलग मॉड्यूल है। अभी बस idea पर ध्यान दीजिए: दो pointers जो एक window बनाते हैं।

⚠️ Common mistakesआम ग़लतियाँ
  • Trying to change a character with s[i] = "x". Strings can't be changed in place: use an array and join().s[i] = "x" से character बदलने की कोशिश। Strings सीधे नहीं बदलतीं: array बनाइए और join() कीजिए।
  • Forgetting to ignore case: "A" !== "a". Use toLowerCase() when the problem says so.Case भूल जाना: "A" !== "a"। सवाल कहे तो toLowerCase() लगाइए।
  • Mixing up slice(a, b): it stops before index b.slice(a, b) में गड़बड़: यह index b से पहले रुकता है।
  • Not checking the lengths first in anagram questions.Anagram वाले सवालों में पहले length check न करना।
