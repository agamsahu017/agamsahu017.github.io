What is an array?Array क्या है?

Think of a train. Every coach has a number: 0, 1, 2, 3… If someone says "coach 3", you walk straight to it. You don't check coaches 0, 1 and 2 first.

एक train सोचिए। हर coach का एक नंबर है: 0, 1, 2, 3… कोई कहे "coach 3", तो आप सीधे वहाँ जाते हैं। पहले 0, 1 और 2 नहीं देखते।

An array stores items in order, and each item has an index starting from 0. Because the computer knows exactly where index i is, reading arr[i] takes O(1) time.

Array items को क्रम से रखता है, और हर item का एक index होता है जो 0 से शुरू होता है। Computer को पता होता है कि index i कहाँ है, इसलिए arr[i] पढ़ने में O(1) time लगता है।

const marks = [72, 85, 90, 64];
console.log(marks[0]);           // 72  (first item)
console.log(marks.length);       // 4
console.log(marks[marks.length - 1]); // 64 (last item)
marks[1] = 88;                   // update: O(1)

5 patterns for array interview questionsArray interview सवालों के 5 patterns

Most array questions are one of these patterns in disguise. Learn to spot them, and you won't need to memorise hundreds of answers.

ज़्यादातर array सवाल इन्हीं patterns में से किसी एक का रूप होते हैं। इन्हें पहचानना सीख लिया, तो सैकड़ों जवाब रटने की ज़रूरत नहीं।

Pattern 1: Hash map to remember what you've seenPattern 1: जो देखा उसे hash map में याद रखो Beginnerशुरुआती

Two Sum: find two numbers that add up to a target. The brute force checks every pair: O(n²). Instead, for each number, ask "have I already seen the number I need?"

Two Sum: ऐसे दो numbers ढूँढो जिनका जोड़ target हो। Brute force हर जोड़ी check करता है: O(n²)। इसके बजाय, हर number पर पूछो "जिस number की मुझे ज़रूरत है, क्या वो पहले देख चुका हूँ?"

// Brute force: O(n²) time, O(1) space
function twoSumSlow(nums, target) {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] + nums[j] === target) return [i, j];
    }
  }
  return [];
}

// Better: O(n) time, O(n) space
function twoSum(nums, target) {
  const seen = new Map(); // value -> index
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
  return [];
}

twoSum([2, 7, 11, 15], 9); // [0, 1]

Pattern 2: Two pointersPattern 2: Two pointers Beginnerशुरुआती

Use two indexes that move towards each other, or one slow and one fast. Move Zeroes: push all zeros to the end, keeping the order of other numbers, without a new array.

दो indexes इस्तेमाल करो जो एक-दूसरे की ओर बढ़ें, या एक धीमा और एक तेज़। Move Zeroes: सारे zero आख़िर में भेजो, बाक़ी numbers का क्रम वही रखो, और नया array मत बनाओ।

// O(n) time, O(1) extra space
function moveZeroes(nums) {
  let slow = 0; // where the next non-zero should go
  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      [nums[slow], nums[fast]] = [nums[fast], nums[slow]]; // swap
      slow++;
    }
  }
  return nums;
}

moveZeroes([0, 1, 0, 3, 12]); // [1, 3, 12, 0, 0]

Pattern 3: Track the best so farPattern 3: अब तक का सबसे अच्छा याद रखो Beginnerशुरुआती

Best Time to Buy and Sell Stock: walk through the prices once, remember the lowest price so far, and check the profit if you sold today.

Best Time to Buy and Sell Stock: prices पर एक बार चलो, अब तक की सबसे कम price याद रखो, और देखो आज बेचते तो कितना profit होता।

// O(n) time, O(1) space
function maxProfit(prices) {
  let minPrice = Infinity;
  let best = 0;
  for (const price of prices) {
    minPrice = Math.min(minPrice, price);
    best = Math.max(best, price - minPrice);
  }
  return best;
}

maxProfit([7, 1, 5, 3, 6, 4]); // 5 (buy at 1, sell at 6)

Pattern 4: Prefix sumPattern 4: Prefix sum Next level · optional on first readNext level · पहली बार में optional

If you need the sum of many ranges, pre-compute running totals once. Then any range sum is just one subtraction.

अगर बहुत सारी ranges का sum चाहिए, तो पहले एक बार running total बना लो। फिर किसी भी range का sum बस एक घटाव है।

function buildPrefix(nums) {
  const prefix = [0];
  for (const x of nums) prefix.push(prefix[prefix.length - 1] + x);
  return prefix; // prefix[i] = sum of first i items
}

const nums = [3, 1, 4, 1, 5];
const prefix = buildPrefix(nums);        // [0, 3, 4, 8, 9, 14]
// Sum from index 1 to 3 (1 + 4 + 1):
const rangeSum = prefix[4] - prefix[1];  // 9 - 3 = 6, in O(1)

Pattern 5: Kadane's algorithm (maximum subarray)Pattern 5: Kadane's algorithm (maximum subarray) Next level · optional on first readNext level · पहली बार में optional

Find the contiguous part of the array with the largest sum. At each number, decide: "is it better to continue the current subarray, or start fresh from here?"

Array का वो लगातार हिस्सा ढूँढो जिसका sum सबसे बड़ा हो। हर number पर तय करो: "मौजूदा subarray को आगे बढ़ाना बेहतर है, या यहीं से नया शुरू करना?"

// O(n) time, O(1) space
function maxSubArray(nums) {
  let current = nums[0];
  let best = nums[0];
  for (let i = 1; i < nums.length; i++) {
    current = Math.max(nums[i], current + nums[i]); // continue or restart
    best = Math.max(best, current);
  }
  return best;
}

maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4]); // 6 ([4, -1, 2, 1])

Interview checklist for array questionsArray सवालों के लिए interview checklist

Before writing code, ask these questions. Interviewers like candidates who clarify first.

Code लिखने से पहले ये सवाल पूछिए। Interviewers को ऐसे candidates पसंद आते हैं जो पहले बात साफ़ करते हैं।

  • Is the array sorted? (Sorted often means two pointers or binary search.)क्या array sorted है? (Sorted का मतलब अक्सर two pointers या binary search होता है।)
  • Can there be negative numbers, duplicates or an empty array?क्या negative numbers, duplicates या ख़ाली array हो सकता है?
  • Can I change the input array, or must I return a new one?क्या मैं input array बदल सकता हूँ, या नया array लौटाना है?
  • What should I return if there is no answer?कोई जवाब न हो तो क्या return करूँ?

🎤 Say it like this: "I'll use a hash map to store each number's index as I go. For every number, I check if target minus that number is already in the map. That's one pass, so O(n) time and O(n) space."

🎤 ऐसे बोलिए: "I'll use a hash map to store each number's index as I go. For every number, I check if target minus that number is already in the map. That's one pass, so O(n) time and O(n) space."

Edge cases to test out loud: empty array, one item, all same values, all negative values, and very large input.

ये edge cases बोलकर test कीजिए: ख़ाली array, एक item, सारी values एक जैसी, सारी values negative, और बहुत बड़ा input।

⚠️ Common mistakesआम ग़लतियाँ
  • Off-by-one: looping with i <= arr.length. The last index is arr.length − 1.Off-by-one: i <= arr.length तक loop चलाना। आख़िरी index arr.length − 1 है।
  • Using sort() on numbers without (a, b) => a - b.Numbers पर (a, b) => a - b के बिना sort() चलाना।
  • Starting a minimum at 0 instead of Infinity (or the first item). It breaks when all numbers are positive.Minimum को Infinity (या पहले item) की जगह 0 से शुरू करना। सारे numbers positive हों तो यह ग़लत हो जाता है।
  • Changing the array while looping over it with splice, which shifts the indexes.Loop चलाते हुए splice से array बदलना, जिससे index खिसक जाते हैं।
  • Forgetting the empty array case.ख़ाली array वाला case भूल जाना।
