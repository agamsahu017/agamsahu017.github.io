Variables, values and decisionsVariables, values और फ़ैसले

A variable is a named box that holds a value. Use const when the value won't change, and let when it will.

Variable एक नाम वाला डिब्बा है जिसमें value रखी जाती है। Value नहीं बदलेगी तो const, बदलेगी तो let इस्तेमाल कीजिए।

const name = "Riya";   // text (string)
let score = 40;        // number
score = score + 10;    // now 50
const passed = true;   // boolean: true or false

console.log(name, score, passed); // Riya 50 true

Making decisions with if / elseif / else से फ़ैसले

const marks = 72;

if (marks >= 90) {
  console.log("Grade A");
} else if (marks >= 60) {
  console.log("Grade B"); // this runs
} else {
  console.log("Try again");
}

Always use ===, not ==. The double == converts types and gives surprises: "5" == 5 is true.

हमेशा === लिखिए, == नहीं। == type बदल देता है और चौंकाता है: "5" == 5 भी true है।

Loops: repeat workLoops: काम दोहराना

Almost every DSA solution has a loop. Learn these three well.

लगभग हर DSA solution में loop होता है। ये तीन अच्छे से सीख लीजिए।

1. The for loop (when you need the index)1. for loop (जब index चाहिए) Beginnerशुरुआती

const nums = [4, 8, 15];
for (let i = 0; i < nums.length; i++) {
  console.log("index", i, "value", nums[i]);
}

ध्यान दीजिए: index 0 से length − 1 तक जाते हैं। इसीलिए condition i < nums.length है, <= नहीं।

2. for...of (when you only need the values)2. for...of (जब सिर्फ़ values चाहिए) Beginnerशुरुआती

for (const n of nums) {
  console.log(n); // 4, then 8, then 15
}

3. while (when you don't know how many times)3. while (जब पता न हो कितनी बार) Beginnerशुरुआती

let n = 20;
while (n > 1) {
  n = Math.floor(n / 2); // 10, 5, 2, 1
}
console.log(n); // 1

break stops a loop early. continue skips to the next round.

break loop को जल्दी रोक देता है। continue सीधे अगले round पर भेजता है।

Functions: reusable stepsFunctions: बार-बार काम आने वाले steps

In DSA, every answer is a function: it takes input (parameters) and returns output. LeetCode gives you the function name, and you fill in the body.

DSA में हर जवाब एक function होता है: वो input (parameters) लेता है और output return करता है। LeetCode आपको function का नाम देता है, और आप उसके अंदर code लिखते हैं।

// Normal function
function add(a, b) {
  return a + b;
}

// Arrow function: a shorter way to write the same thing
const multiply = (a, b) => a * b;

console.log(add(2, 3));      // 5
console.log(multiply(2, 3)); // 6

return ends the function immediately. Code written after return never runs. If you forget return, the function gives undefined.

return function को तुरंत ख़त्म कर देता है। return के बाद लिखा code कभी नहीं चलता। return भूल गए, तो function undefined देता है।

Useful built-in helpersकाम के built-in helpers

Math.max(3, 9, 4);    // 9

Math.floor(7 / 2);    // 3 (removes the decimal)
Math.abs(-5);         // 5

Map: a fast lookup tableMap: तेज़ lookup table Beginnerशुरुआती

A Map stores key → value pairs. Checking and reading a key is O(1), very fast. You'll use it in almost every module.

Map key → value जोड़े रखता है। Key check करना और पढ़ना O(1) है, बहुत तेज़। आप इसे लगभग हर मॉड्यूल में इस्तेमाल करेंगे।

const age = new Map();
age.set("Aman", 20);          // add
age.set("Riya", 22);
console.log(age.get("Riya")); // 22
console.log(age.has("Ravi")); // false
console.log(age.size);        // 2

// Counting things: a very common pattern
const count = new Map();
for (const ch of "hello") {
  count.set(ch, (count.get(ch) || 0) + 1);
}
console.log(count.get("l"));  // 2

Set: unique values onlySet: सिर्फ़ unique values Beginnerशुरुआती

const seen = new Set([1, 2, 2, 3]);
console.log(seen.size);       // 3 (duplicate 2 removed)
seen.add(4);
console.log(seen.has(2));     // true, in O(1)

Two handy tricks you'll see in solutionsSolutions में दिखने वाली दो काम की tricks

// 1. Swap two values without a temp variable
let a = 1, b = 2;
[a, b] = [b, a];              // now a = 2, b = 1

// 2. Sort numbers correctly
const marks = [40, 100, 9];
marks.sort((x, y) => x - y);  // [9, 40, 100]

How to solve any coding problem: 5 stepsकिसी भी coding सवाल को हल करने के 5 steps

Staring at an empty screen is normal. Follow these steps every time, and you'll always know what to do next.

ख़ाली screen देखकर अटकना normal है। हर बार ये steps follow कीजिए, तो हमेशा पता रहेगा कि आगे क्या करना है।

  1. Understand. Read the problem twice. Say in your own words what goes in and what must come out.समझो। सवाल दो बार पढ़ो। अपने शब्दों में बोलो कि input क्या है और output क्या चाहिए।
  2. Example by hand. Take a small example and solve it on paper, without code. Notice what steps you did.हाथ से example। एक छोटा example लो और बिना code के काग़ज़ पर हल करो। देखो तुमने कौन-से steps किए।
  3. Brute force first. Write the simplest solution that works, even if it is slow. A working slow answer beats a broken fast one.पहले brute force। सबसे आसान solution लिखो जो चले, भले धीमा हो। चलने वाला धीमा जवाब, टूटे हुए तेज़ जवाब से बेहतर है।
  4. Improve. Ask: "am I repeating work?" A hash map, two pointers or sorting often removes a loop.बेहतर करो। पूछो: "क्या मैं काम दोहरा रहा हूँ?" Hash map, two pointers या sorting से अक्सर एक loop हट जाता है।
  5. Test. Dry run your code on the example, then on edge cases: empty input, one item, duplicates, negatives.Test करो। Example पर code का dry run करो, फिर edge cases पर: ख़ाली input, एक item, duplicates, negatives।
⚠️ Common mistakesआम ग़लतियाँ
  • Using <= instead of < in a loop, and reading arr[arr.length], which is undefined.Loop में < की जगह <= लिखना, और arr[arr.length] पढ़ना, जो undefined है।
  • Forgetting return at the end of a function.Function के आख़िर में return भूल जाना।
  • Using == instead of ===.=== की जगह == लिखना।
  • Using const for a value you later change, which gives an error.बाद में बदलने वाली value के लिए const लिखना, जिससे error आता है।
  • Copying solutions without typing and running them yourself.Solution ख़ुद type करके चलाए बिना copy कर लेना।

Exercise 1: Write a function sumArray(nums) that returns the sum of all numbers.Exercise 1: एक function sumArray(nums) लिखिए जो सारे numbers का जोड़ लौटाए।

Show answerजवाब देखें
function sumArray(nums) {
  let total = 0;
  for (const n of nums) total += n;
  return total;
}
console.log(sumArray([1, 2, 3])); // 6

Exercise 2: Write countEven(nums) that returns how many numbers are even.Exercise 2: countEven(nums) लिखिए जो बताए कितने numbers even हैं।

Show answerजवाब देखें
function countEven(nums) {
  let count = 0;
  for (const n of nums) {
    if (n % 2 === 0) count++;
  }
  return count;
}
console.log(countEven([1, 2, 4, 7])); // 2

Exercise 3: Write findMax(nums) without using Math.max.Exercise 3: Math.max इस्तेमाल किए बिना findMax(nums) लिखिए।

Show answerजवाब देखें
function findMax(nums) {
  let max = -Infinity;
  for (const n of nums) {
    if (n > max) max = n;
  }
  return max;
}
console.log(findMax([3, 9, 2])); // 9

Exercise 4: Write hasDuplicate(nums) that returns true if any number appears twice. Use a Set.Exercise 4: hasDuplicate(nums) लिखिए जो true लौटाए अगर कोई number दो बार आए। Set इस्तेमाल कीजिए।

Show answerजवाब देखें
function hasDuplicate(nums) {
  const seen = new Set();
  for (const n of nums) {
    if (seen.has(n)) return true;
    seen.add(n);
  }
  return false;
}
console.log(hasDuplicate([1, 2, 3, 1])); // true

Exercise 5: Write countWords(words) that returns a Map of each word and how many times it appears.Exercise 5: countWords(words) लिखिए जो हर शब्द और उसकी गिनती का Map लौटाए।

Show answerजवाब देखें
function countWords(words) {
  const count = new Map();
  for (const w of words) {
    count.set(w, (count.get(w) || 0) + 1);
  }
  return count;
}
console.log(countWords(["hi", "ok", "hi"])); // Map { "hi" => 2, "ok" => 1 }
